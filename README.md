# WASDify

[English](README.en.md) · [Документация](docs/README.md)

Коллекция точечных бинарных патчей для старых игр: современное управление,
исправление важных ошибок и оптимизация с сохранением исходного игрового опыта.
Характерный пример — управление WASD и мышью в DOS-шутерах.

WASDify предоставляет общий движок, CLI и GUI. Пользователь выбирает игру,
целевой EXE и нужные патчи. Известные версии определяются по SHA-256; для
реализованных патчей совместимость проверяется по сигнатурам и исходным байтам.
Зависимости нужно выбирать явно.

## Текущий статус

Работают оболочка, определение файлов, планирование, сигнатурный поиск,
проверка зависимостей, безопасная запись и бэкапы. Интерфейс — русский и английский.

Первая поддерживаемая игра — **«Подземелья Кремля» / Dungeons of Kremlin**.
Описание патчей, совместимые версии, инструкции и результаты проверок —
в [документации игры](docs/games/dungeons-of-kremlin/README.md).

## Установка

Для «Подземелий Кремля» доступны [настройки через DOS setup и INI](docs/games/dungeons-of-kremlin/settings.md):
патч `game-settings` вместе с явно выбранными `wasd` и `resolution-640x400`.
Русский setup: `wasdify setup C:\Games\Kremlin\RUS --setup-lang ru`, английский:
`wasdify setup C:\Games\Kremlin\ENG --setup-lang en`. Язык DOS setup независим
от языка интерфейса WASDify. Основной EXE игры читает настройки самостоятельно.

Нужны **Python 3.11 или новее** и Tcl/Tk для GUI. Windows — основная проверяемая
платформа. Минимальная версия Python повышается только по технической необходимости
с отдельным согласованием. Зависимостей времени выполнения вне стандартной библиотеки нет.

PowerShell, из корня репозитория:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\wasdify.exe --lang ru games
.\.venv\Scripts\wasdify.exe gui --lang ru
```

Вместо `-3.11` можно указать установленную более новую версию, например `-3.14`.
Активация venv не обязательна. Для запуска GUI также есть
`.\.venv\Scripts\wasdify-gui.exe --lang ru`.

## Сборка Windows EXE

Из корня репозитория:

```powershell
.\build.ps1
```

Результат — один автономный **`dist\WASDify.exe`**, которому не нужен установленный Python:

- Двойной щелчок или запуск без аргументов открывает GUI; собственная консоль скрывается при старте.
- Команды запускают CLI: `.\dist\WASDify.exe --lang ru games`. Вывод, перенаправления
  и коды завершения работают в терминале.
- Явный запуск GUI с выбором языка: `.\dist\WASDify.exe gui --lang ru`.

Можно перенести EXE в другую папку. Каталог игр, переводы и Tcl/Tk включены в сборку;
содержимое `originals/` и `mqa/` не включается.

Сборка требует Windows, Python 3.11+ с Tcl/Tk и интернет для первой установки
инструментов. Скрипт создаёт отдельное окружение в `build\exe\venv`, используя
Python из `.venv`, если она существует, иначе `py -3`. Затем устанавливает
пакет с дополнительной группой `exe` и запускает PyInstaller. Промежуточные файлы
лежат в `build\exe\`; `build/` и `dist/` исключены из Git. После сборки выполняется
проверка автономного CLI, ресурсов RU/EN, кодов завершения и справки команды GUI.
Устаревший `dist\wasdify-cli.exe` от предыдущей сборки удаляется после успешных проверок.

Если запуск PowerShell-скриптов ограничен локальной политикой, используйте:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Этот параметр действует только для запущенного процесса PowerShell.

## CLI

После активации venv или с полным путём к команде:

```text
wasdify --lang ru games
wasdify detect "C:\Games\Kremlin\PKR.EXE"
wasdify patches --game dungeons-of-kremlin
wasdify apply "C:\Games\Kremlin\PKR.EXE" --patch wasd
wasdify gui
python -m wasdify --help
```

`plan` никогда не пишет файлы. `apply` заново проверяет набор перед записью.
Для неизвестного EXE параметр `--game <game-id>` задаёт контекст анализа
и не обходит проверки совместимости патчей. Инструкции по запуску конкретной
игры находятся в её документации.

Общие параметры `--lang ru|en` и `--json` принимаются до и после команды.
Язык по умолчанию определяется системной локалью: `ru` → русский, иначе английский.
JSON содержит стабильные английские ключи, коды диагностики и байты в hex.
`--json` неприменим к запуску GUI. Справка доступна через `--help`.

| Код | Значение |
|---|---|
| 0 | Операция выполнена, план допустим или изменения уже применены |
| 2 | Некорректные аргументы |
| 3 | Несовместимость, неизвестный файл или недопустимый набор |
| 4 | Ошибка чтения, записи, бэкапа или недоступный GUI |
| 5 | Выбран патч-заглушка |

## GUI и бэкапы

Выберите EXE через «Обзор» — известная игра определится автоматически. Затем
отметьте нужные патчи и нажмите «Проверить». Результат содержит версию, SHA-256 и
диагностику. «Применить» доступно только для успешно проверенного набора.
Изменение выбора требует новой проверки. RU/EN переключается в окне.

Бэкап включён по умолчанию. При реальном изменении создаётся уникальный файл
`<EXE>.wasdify-<uuid>.bak` рядом с оригиналом. Отключение: `--no-backup` в CLI
или флажок в GUI. При ошибке бэкапа запись прекращается. Если замена EXE не удалась,
уже созданный проверенный бэкап сохраняется. Повторное применение без изменений
не создаёт новый бэкап. Для восстановления закройте игру и скопируйте бэкап поверх EXE.

Первая версия записывает один основной EXE за операцию. Запускайте патчер при
закрытой игре; не редактируйте целевой файл одновременно другими программами.

## Разработка и материалы

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
```

Тесты используют только синтетические бинарные данные. CI проверяет Windows,
Python 3.11 и актуальную стабильную версию Python. NASM используется разработчиками
для воспроизводимой сборки вставок WASD; для запуска оболочки он не нужен.

- [Архитектура и добавление патчей](docs/architecture.md)
- [Документация первой игры](docs/games/dungeons-of-kremlin/README.md)
- [Правила работы агентов](AGENTS.md)

В `docs/games/<game-id>/` хранятся документация и результаты анализа каждой игры.
Оригинальные EXE, исходные материалы и полные дампы храните в `originals/`:
папка целиком исключена из Git. Игровые файлы в поставку не входят.
Папка `mqa/` также целиком исключена: она предназначена для DOSBox и рабочих
копий игр для анализа.
