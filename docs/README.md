Для каждой игры создаётся `docs/games/<game-id>/` с `README.md`, `versions.md`,
`analysis.md` и `patches.md`. Здесь хранятся проверяемые результаты анализа,
заметки, небольшие таблицы и производные артефакты, пригодные для публикации.
Оригинальные материалы и полные дампы находятся в игнорируемой папке `originals/`.
DOSBox и рабочие копии игр для анализа — в игнорируемой папке `mqa/`.
