# Подземелья Кремля / Dungeons of Kremlin

Для уровней 1–3 RUS и ENG подготовлены [автономные сохранения F5/F9](save-load-levels.md).
Это исследовательская игровая копия без Python-моста; установки `save-load`
через WASDify пока нет. [Текущий план и границы поддержки](save-load-status.md).

Для быстродействия в DOSBox Staging 0.83 сначала настройте секцию `[cpu]`
в используемом `dosbox-staging.conf` и перезапустите эмулятор:

```ini
[cpu]
core = dynamic
cpu_cycles_protected = max
```

Настройка решила проблему пользователя. В диагностическом стенде оригинальный
PKR.EXE в 640×480 ускорился примерно с 14 до 275 FPS при переходе с
`normal/60000` на `dynamic/max`.

Готовый `render-optimization` остаётся необязательным улучшением: он сокращает
горизонтальное текстурирование на две инструкции на пиксель и дал +6,8–10,5%
к медиане FPS RUS при `normal/60000`. Дальнейшая оптимизация снята с активного
плана. [Проверки и ограничения](render.md); [методика и замеры](benchmark.md).

ID в WASDify: `dungeons-of-kremlin`. Целевой файл первой версии — основной EXE,
роль `main`. В базе есть русский `PKR.EXE` и английский `PKE.EXE`.

Реализован `resolution-640x400`: исправляет `-r1` одним байтом в RUS/ENG.
Реализован `wasd`: физические W/S, независимые A/D и прямой поворот мышью.
Стрелки сохранены, мышь включается автоматически, Y отключена.
Пользователь подтвердил работу в игре. Подбор чувствительности на разных
компьютерах остаётся дальнейшим плейтестингом. [Подробности](wasd.md).
Есть сигнатурный детектор и распознавание применённых патчей.
Оптимизация реализована; замеры RUS выполнены на диагностических копиях.
Игровые файлы не распространяются.

`game-settings` добавляет чтение KREMLIN.INI основным EXE: разрешение,
чувствительность 0–9 и две клавиши на действие. Требует явного выбора `wasd`
и `resolution-640x400`. Русский/английский DOS setup выгружается отдельно
для соответствующей версии игры; подробности и проверки — в [settings.md](settings.md).


## Применение патчей

В WASDify реализованы семь патчей для RUS/ENG; описание и статус
каждого приведены в [таблице патчей](patches.md). Несовместимый патч блокирует
весь выбранный набор до записи и создания бэкапа.

Примеры CLI для рабочей копии игры (для ENG замените `PKR.EXE` на `PKE.EXE`):

```powershell
wasdify patches --game dungeons-of-kremlin
wasdify apply "C:\Games\Kremlin\PKR.EXE" --patch wasd
wasdify plan "C:\Games\Kremlin\PKR.EXE" --patch resolution-640x400
wasdify apply "C:\Games\Kremlin\PKR.EXE" --patch resolution-640x400
```

Для автономной сборки используйте `WASDify.exe` вместо `wasdify`.
Для неизвестного EXE `--game dungeons-of-kremlin` задаёт контекст анализа,
но не обходит проверку сигнатур и исходных байтов. Детектор распознаёт
подходящий контекст оригинального и исправленного EXE.

Исправление разрешения меняет один байт после проверки уникальной сигнатуры
в NE-коде и распознаёт повторное применение. Запускайте игру с `-r1`
в DOS/DOSBox; `-r2` сохраняет 640×480. Для обеих версий выполнены анализ
и эмуляция; отдельная визуальная проверка патча разрешения в DOSBox ожидается.
[Находки и ограничения](analysis.md).

Чувствительность мыши в WASD-патче по умолчанию — 0,2° на единицу счётчика.
Подбор для разных компьютеров и настроек DOSBox остаётся дальнейшим плейтестингом.
[Управление и проверки](wasd.md).

При применении `game-settings` нужный RU/EN `SETUP.EXE` автоматически устанавливается
рядом с EXE игры. Для автономной версии храните `WASDify.pak` рядом с `WASDify.exe`.
[Подробности установки и восстановления](settings.md#установка-и-использование).
