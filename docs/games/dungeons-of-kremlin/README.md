# Подземелья Кремля / Dungeons of Kremlin

Для быстродействия в DOSBox Staging 0.83 сначала настройте секцию `[cpu]`
в используемом `dosbox-staging.conf` и перезапустите эмулятор:

```ini
[cpu]
core = dynamic
cpu_cycles_protected = max
```

Настройка решила проблему пользователя. В диагностическом стенде оригинальный
PKR.EXE в 640×480 ускорился примерно с 14 до 275 FPS при переходе с
`normal/60000` на `dynamic/max`.

Готовый `render-optimization` остаётся необязательным улучшением: он сокращает
горизонтальное текстурирование на две инструкции на пиксель и дал +6,8–10,5%
к медиане FPS RUS при `normal/60000`. Дальнейшая оптимизация снята с активного
плана. [Проверки и ограничения](render.md); [методика и замеры](benchmark.md).

ID в WASDify: `dungeons-of-kremlin`. Целевой файл первой версии — основной EXE,
роль `main`. В базе есть русский `PKR.EXE` и английский `PKE.EXE`.

Реализован `resolution-640x400`: исправляет `-r1` одним байтом в RUS/ENG.
Реализован `wasd`: физические W/S, независимые A/D и прямой поворот мышью.
Стрелки сохранены, мышь включается автоматически, Y отключена.
Пользователь подтвердил работу в игре. Подбор чувствительности на разных
компьютерах остаётся дальнейшим плейтестингом. [Подробности](wasd.md).
Есть сигнатурный детектор и распознавание применённых патчей.
Оптимизация реализована; замеры RUS выполнены на диагностических копиях.
Игровые файлы не распространяются.
