# Патчи

| ID | Назначение | Зависимости | Конфликты | Статус |
|---|---|---|---|---|
| `wasd` | WASD-управление | Нет | Нет | Заглушка |
| `resolution-640x400` | Исправление недоступности 640×400 | Нет | Нет | Заглушка |
| `render-optimization` | Оптимизация отрисовки с сохранением вида игры | Нет | Нет | Заглушка |

Все патчи независимы, целевой файл — `main`. Изменение игры, ремейк и
переосмысление механик не являются целью WASDify.

Планирование выбранной заглушки возвращает `not_implemented`. Применение всего
набора блокируется, исходный EXE и файловая система игры остаются без изменений.
Совместимость реальных патчей с указанными версиями пока не подтверждена.

При реализации документировать проверяемые сигнатуры, допустимые версии,
исходные и изменённые состояния, побочные эффекты, тестирование в игре,
измерения производительности для оптимизаций и способ восстановления.
